# Wave Reels

Конвейер вертикального видео: сценарий и словная разметка → HTML/WebGL →
покадровый рендер Chromium → MP4. Состояние кадра вычисляется из времени;
сцены привязаны к фразам сценария. Исходные материалы команды и реальные
озвучки заменены демонстрационным примером.

## Быстрый старт

Нужны Python 3.10+ и Chrome/Chromium.

```sh
python -m venv .venv
# Активируйте окружение стандартным способом для своей ОС.
python -m pip install -r requirements.txt
python -m playwright install chromium
python tools/demo.py
```

`tools/demo.py` создаёт синтетическую разметку и тишину, затем собирает
`engine/out2.html`. Запустите `python -m http.server 8000 --bind 127.0.0.1`
и откройте `http://127.0.0.1:8000/engine/out2.html`.

Для короткого видео:

```sh
python engine/render2.py video build/demo/silence.wav 4 build/demo/demo.mp4
```

В примере нет речи: это проверка рендера и анимации, а не результат TTS.
Поставьте собственную разрешённую озвучку и её разметку для настоящего выпуска.
Для распознавания дополнительно установите `requirements-asr.txt`;
`tools/asr.py AUDIO WORDS.json` использует локальный Whisper.

## Структура

- `engine/` — сборщик сценария, плеер и рендер.
- `examples/` — вымышленный демонстрационный сценарий.
- `tools/` — разметка речи, обработка пауз, поиск ассетов и проверка видео.
- `assets/` — шрифты, иконки, карты и модели с атрибуцией.
- `reference/` — формат сценариев и описание визуальных блоков.

FFmpeg выбирается через `WAVE_FFMPEG` или пакет imageio-ffmpeg;
путь к браузеру можно задать через `WAVE_CHROME`.
Внешние сервисы и API-ключи для демонстрации не нужны.
Лицензия кода — MIT; условия сторонних ассетов сохранены в `ATTRIBUTION.md`
и соответствующих файлах лицензий. Создание собственного ролика не выполняет
публикацию в социальные сети.
