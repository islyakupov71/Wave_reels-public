# Словарь кадра

В сцене два яруса. Сверху — **носитель кадра** (`visual`), ровно один или ни одного.
Снизу — **блоки** (`blocks`), карточки с текстом и числами.

У блока и у носителя есть `at` — фраза-якорь из закадрового текста. Сборщик сам
подставит секунду. У носителя `at` необязателен: по умолчанию он равен началу сцены.
`stagger=True` заставляет дочерние элементы появляться по одному с шагом 0.13 с.

---

# Носители кадра

Полная таблица «что в сцене → какой носитель» — в скилле `reel`, раздел «Выбор
носителя». Здесь только синтаксис.

## model — 3D-модель

```python
visual=dict(type="model", model="car-kit/Models/GLB format/truck.glb",
            size=0.46, spin=0.12, yaw=1.6)
```

`size` 0.3–0.5 доля кадра, `spin` скорость вращения (0.10–0.20), `yaw` стартовый угол —
подбирается на сэмплах. Пути моделей — `assets/models/library.json`, 48 штук.

Старая запись `hero=dict(model=...)` продолжает работать: сборщик превращает её
в `visual` с `type="model"`.

**Модель ставится только тогда, когда она — тот самый предмет, о котором речь.**

## flow — цепочка шагов

Процесс, последовательность, передача из рук в руки. 3–5 шагов, больше не влезает.

```python
visual=dict(type="flow", steps=[
    dict(name="Произвели",   note="код создан",        icon="factory"),
    dict(name="Переместили", note="между участниками", icon="truck"),
    dict(name="Продали",     note="касса считала",     icon="cash-register"),
    dict(name="Вывели",      note="путь закрыт",       icon="check-circle", tone="warn"),
])
```

`tone="warn"` красит плашку иконки в коралловый. Шаги появляются по одному со стрелками.

## icons — сетка иконок

Перечисление разнородных сущностей, у которых нет общей шкалы.

```python
visual=dict(type="icons", cols=3, items=[
    dict(name="Уникальность", icon="fingerprint"),
    dict(name="Штраф",        icon="gavel", tone="warn"),
])
```

`cols` по умолчанию — число элементов, но не больше трёх. Подбор иконки:
`python tools/icons.py <русское слово>`.

## stack — стопка слоёв

Из чего складывается величина, когда важен и состав, и вклад каждой части.

```python
visual=dict(type="stack", items=[
    dict(name="Хранение",  v="70 ₽", icon="warehouse"),
    dict(name="Реклама",   v="40 ₽", icon="megaphone", tone="neg"),
])
```

## map — карта России или мира

География, маршруты, расстояния, кластеры.

```python
visual=dict(type="map", map="russia",
            routes=[dict(**{"from": "Москва", "to": "Владивосток"}, tone="neg", bend=0.22)],
            points=[dict(name="Москва", tone="pos"),
                    dict(name="Владивосток", label="ДВФО", dx=18, dy=-16)])
```

`map`: `russia` (Альберса) или `world` (Миллер). Города — 34 точки в
`assets/maps/maps.json`, включая Пекин, Шанхай, Стамбул, Дубай, Алматы.
Дуги прорисовываются, точки всплывают. `bend` — кривизна дуги, `label=False` прячет подпись.
Города нет в списке — добавь координаты в `CITIES` в `tools/build_assets.py` и пересобери.

## donut — кольцо долей

Доли одного целого. Три-четыре сектора, больше не читается.

```python
visual=dict(type="donut", center="36%", sub="осталось", items=[
    dict(name="Хранение", pct=28, val="70 ₽"),
    dict(name="Осталось", pct=36, val="90 ₽", tone="neg"),
])
```

`center` набегает счётчиком. Сектора прорисовываются по кругу.

## columns — столбцы

Сравнение величин между собой. `v` — число для высоты, `val` — подпись.

```python
visual=dict(type="columns", max=100, items=[
    dict(name="без налога",  v=50, val="50 коп"),
    dict(name="за 100 штук", v=100, val="61 ₽", tone="neg"),
])
```

В `name` можно `\n` — подпись переносится на вторую строку.

## timeline — шкала времени

Годы, этапы, «было — стало».

```python
visual=dict(type="timeline", marks=[
    dict(year="2019", name="старт\nсистемы"),
    dict(year="2026", name="сейчас", tone="hi"),
])
```

Ось прорисовывается слева направо, вехи всплывают по одной. `tone="hi"` — коралловая точка.

## line — линия по осям x/y

Одна величина реально зависит от другой на непрерывной шкале — не для красоты,
а когда есть настоящий x и настоящий y (доля от объёма, ставка от срока и т.п.).

```python
visual=dict(type="line", maxX=100, yTop="240 тыс ₽", points=[
    dict(x=0,   y=0),
    dict(x=50,  y=120000, label="50%",  val="120 тыс ₽", tone="neg"),
    dict(x=100, y=240000, label="100%", val="240 тыс ₽"),
])
```

Линия прорисовывается слева направо, точки с `val` всплывают крупнее и подписаны
числом. `tone="neg"` красит точку и подпись в коралловый. `maxX`/`maxY` — по
умолчанию максимум из точек.

## code — двумерный код или штрихкод

Маркировка, идентификатор, «что зашито внутри».

```python
visual=dict(type="code", text="0104630000000000215Nq7Kx", modules=20, legend=[
    dict(name="14 цифр",        note="номер товарной позиции", tone="hi",  weight=3),
    dict(name="Серийный номер", note="эта конкретная единица", tone="hi2", weight=3),
    dict(name="Ключ проверки",  note="4 символа",              tone="hi3", weight=1),
])
visual=dict(type="code", kind="barcode", text="4607177993720")
```

Картинка детерминированно строится из `text`: один и тот же текст — один и тот же узор.
`legend` красит вертикальные зоны кода и рисует расшифровку справа; `weight` — ширина зоны.

**Это иллюстрация, а не рабочий код.** Не называй её сканируемым Data Matrix
ни в кадре, ни в закадровом тексте.

## image — фото, скрин, чужой логотип

```python
visual=dict(type="image", src="../assets/photos/sklad.jpg", cap="склад в Подольске")
visual=dict(type="image", src="../assets/logos/brands/dhl.svg", plate=True)
```

`plate=True` кладёт картинку на белую подложку — нужно для одноцветных логотипов,
иначе они пропадают на тёмной теме. Пути — относительно `engine/`.

# Блоки

## note — карточка с акцентной полосой
```python
dict(at="Дороже", type="note", tone="warn", label="правило",
     text="день простоя дороже разницы — <b>вези быстрее</b>")
```
`tone`: `warn` коралловый, `good` синий. В тексте `<b>` синий акцент, `<i>` коралловый.

## stat — показатель
```python
dict(at="Восемьсот", type="stat", k="за килограмм", v="850 — 1 400 ₽", tone="neg")
```
`tone`: `neg` коралловый, `pos` синий. Число набегает счётчиком.

## big — крупное число
```python
dict(at="Партия", type="big", label="заморожено в пути", v="1 000 000 ₽", tone="accent")
```

## kpi — ряд из двух-четырёх чисел
```python
dict(at="без налога", type="kpi", items=[
    dict(name="один код", v="50 копеек", tone="accent"),
    dict(name="с налогом", v="61 копейка")])
```

## range — шкала диапазона
```python
dict(at="Семь", type="range", cap="7 — 12 дней", max=70, ticks=[0,20,40,70],
     **{"from":7,"to":12}, tone="slow", ghostTo=70)
```
`tone="slow"` красит полосу в коралловый. `ghostTo` дорисовывает заштрихованный хвост.

## bars — полосы сравнения
```python
dict(at="Продал", type="bars", stagger=True, items=[
    dict(name="свой кластер", pct=4, val="базовый тариф"),
    dict(name="максимальная", pct=100, val="+12%", tone="neg")])
```

## waterfall — из чего сложилась сумма
```python
dict(at="Складываем", type="waterfall", unit=" ₽", items=[
    dict(name="выручка",  v=250),      # абсолютный старт
    dict(name="хранение", d=-70),      # вычет
    dict(name="осталось", total=True), # накопленный итог
])
```
Столбцы растут снизу, между ними пунктирные связки. `sign=False` убирает плюсы.

## compare — «думаешь» против «на самом деле»
```python
dict(at="Вдвое", type="compare",
     leftLabel="против самолёта", left="срок <i>×2</i>",
     rightLabel="а цена", right="ставка <b>÷2</b>")
```

## table — таблица
```python
dict(at="Главная", type="table", head=["строка", "сумма"], rows=[
    dict(cells=["Хранение", "70 ₽"]),
    dict(cells=["Реклама", "40 ₽"], tone="neg")])
```
Первая колонка шире, вторая прижата вправо. Числа во второй набегают счётчиком.

## checklist — что есть и чего нет
```python
dict(at="Ноль", type="checklist", stagger=True, items=[
    dict(name="Путь товара", note="записан"),
    dict(name="Состав", note="ноль проверок", no=True)])
```
`no=True` — коралловый крест вместо синей галки.

## nums — нумерованный список
```python
dict(at="Разбираю", type="nums", stagger=True, items=[
    dict(name="Самолёт", note="дорого и быстро")])
```

## chips — ряд меток
```python
dict(at="электроника", type="chips", stagger=True,
     items=["электроника", "образцы", "срочная допоставка"])
```

## quote — цитата, норма, чужая формулировка
```python
dict(at="Закон", type="quote",
     text="Маркировка идентифицирует товар и фиксирует его движение.",
     src="статья 1 закона")
```

## logos — ряд логотипов
```python
dict(at="Площадки", type="logos", items=[
    dict(src="../assets/logos/brands/dhl.svg", name="DHL")])
```
Всегда на белой подложке. Российских маркетплейсов в открытых наборах нет —
их файлы просишь у пользователя на шаге визуального плана.

## Как добавить свой тип

1. разметка — в `renderVisual` или `renderBlock` в `engine/player2.html`
2. анимация — через атрибуты, которые уже разбирает `render(t)`:
   `data-num` (счётчик), `data-rect="низ,высота"` (рост столбца),
   `data-len` (прорисовка линии, нужен `pathLength="1"`),
   `data-seg="старт,длина"` (сектор кольца), `data-r` (всплытие точки),
   `data-kid` (элемент появляется в общей череде)
3. новый носитель — в множество `VISUALS` в `engine/build2.py`
4. пример — в `content/scenarios/_selftest.py`, это стенд на все типы сразу
5. описание — сюда

Никаких `transition`, `animation` и таймеров: кадр обязан оставаться чистой
функцией от `t`.
