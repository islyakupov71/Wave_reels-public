# Библиотека ассетов

Пополняется двумя командами:

```
python tools/fetch_assets.py      # качает исходники в ~/.cache/wave-reels-vendor
python tools/build_assets.py      # отбирает нужное в assets/
```

`python` здесь и дальше — это `.venv\Scripts\python.exe`, окружение конвейера.
Папку кэша можно перенести переменной `WAVE_VENDOR`.

Сами наборы в репозиторий не кладём — 60 МБ ради двух сотен файлов не нужны.
В `assets/` попадает только отобранное, вместе с индексами.

## Иконки

**126 штук**, отобраны из [Lucide](https://lucide.dev) (ISC) и
[Tabler](https://tabler.io/icons) (MIT). Обе лицензии разрешают коммерцию без атрибуции.

Все приведены к одному виду: `viewBox 0 0 24 24`, `stroke="currentColor"`, толщина 2.
Цвет задаёт плеер через `color`, перекрашивать файлы не надо.

Индекс с русскими описаниями — `assets/icons/index.json`. Поиск:

```
python tools/icons.py склад возврат      # что есть под эти слова
python tools/icons.py --groups           # все группы
```

Группы: транспорт (12), склад (17), торговля (10), деньги (9), аналитика (10),
документы (16), время (7), оценка (17), схема (14), прочее (16).

Нужной иконки нет — добавь ключ в словарь `ICONS` в `tools/build_assets.py`
и пересобери. Исходные наборы уже лежат в кэше: lucide 1768, tabler 5130.

## Карты

`assets/maps/maps.json` — два готовых SVG-пути и координаты 34 городов.

| Карта | Проекция | Размер | Данные |
|---|---|---|---|
| `russia` | Альберса, 50 м | 1000×549 | Natural Earth 50m |
| `world` | Миллера, 110 м | 1000×491 | Natural Earth 110m |

Источник — [world-atlas](https://github.com/topojson/world-atlas) (ISC),
данные Natural Earth в общественном достоянии. TopoJSON разбирается собственным
кодом в `tools/build_assets.py`, сторонних библиотек не требуется.

Города: 26 российских от Калининграда до Владивостока плюс 8 зарубежных узлов
(Пекин, Шанхай, Гуанчжоу, Урумчи, Стамбул, Дубай, Алматы, Минск) — под сюжеты
про пути из Китая. Координаты уже пересчитаны в систему каждой карты, так что
точки и дуги ставятся по имени города.

Антарктида из мировой карты выброшена: в цилиндрической проекции она даёт
полосу во всю ширину кадра. Разрывы по 180-му меридиану сшиваются порогом
в `to_svg`, иначе Чукотка тянет линию через весь кадр.

## Логотипы брендов

**21 знак** из [Simple Icons](https://simpleicons.org) — лицензия **CC0**.
Мировые перевозчики (DHL, FedEx, UPS), площадки (AliExpress, eBay, Shopify),
платёжные системы, мессенджеры.

**Российских маркетплейсов, банков и госструктур там нет** — Ozon, Wildberries,
Сбер, ЦРПТ и подобные в открытые наборы не входят. Их файлы всегда просишь
у пользователя на шаге визуального плана. Рисовать чужие знаки самому нельзя.

Логотипы кладутся на белую подложку (`plate=True`, блок `logos` делает это сам):
знаки одноцветные и на тёмной теме иначе исчезают.

### Что доработать

Четыре модели выбраны неудачно, при сборке заменю:

| Ключ | Проблема | Замена |
|---|---|---|
| `gate` (`door-wide-open`) | открытая дверь = пустая рамка, в кадре ничего | `structure-doorway-wide` |
| `warehouse` (`structure-tall`) | оказался тонким столбом | `city-kit-industrial/building-*` |
| `warning` (`warning-orange`) | читается как леденец, не как знак | `cone` или `indicator-special-cross` |
| `cargo-pile` | бесформенный ком | `box-large` + `box-wide` группой |

Ещё нужно: **пофайловые повороты**. Модели лежат в разных ориентациях — фура смотрит в камеру, вагон стоит боком. В `library.json` добавится поле `yaw` с базовым углом на каждую модель.

### Чего в библиотеке нет и надо будет генерировать

Kenney покрыл транспорт и склад, но не покрыл документы. Не хватает:

- декларация / пачка бумаг
- планшет со сканером в руке
- штрихкод-этикетка
- печать / штамп
- монета ₽
- песочные часы
- весы

Это семь объектов. Когда дойдём — пришлю тебе промпты одним блоком: единый ракурс, единый свет, прозрачный фон, наша палитра. Приёмку сделаю автоматически (проверю альфу, палитру, ракурс по силуэту, центровку) и верну список брака.

### Норматив по объёму

Ролик 60–90 с = 10–12 сцен, hero-объект уместен в 5–6. Чтобы не повторяться чаще раза в три ролика, нужно ~30 в обороте с учётом тематической применимости. **Сейчас 47 — норматив закрыт с запасом.**

## 3D-движок

`three.js 0.180` — `engine/vendor/`. Проверено:

- WebGL 2.0 в headless Chrome работает через SwiftShader (софтверно, GPU не нужен)
- GLB грузятся и перекрашиваются в бренд
- **28 кадров/с при 540×540** — 3D почти не замедлит рендер
- покадровый детерминизм сохраняется: сцена рендерится синхронно внутри `__setTime(t)`

Единственное требование — отдавать файлы по HTTP, а не `file://`: ES-модули и GLB блокируются CORS. В конвейере поднимается локальный сервер на 127.0.0.1.
